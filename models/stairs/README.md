# 钢制楼梯资源

## 文件

- `steel_stair.STL`：用户提供的原始楼梯模型；
- `geometry_estimate.json`：由原始 STL 解析生成的可落脚面和级高估计；
- 可读尺寸表见 [`../../docs/STAIR_GEOMETRY.md`](../../docs/STAIR_GEOMETRY.md)。

## 基本信息

- 原始单位：毫米；
- 原始文件包围盒：约 `4086.866 × 1406.850 × 936.000 mm`；
- MuJoCo 导入缩放：`0.001`；
- 当前静态场景中的世界尺寸：`4.086866 × 0.936000 × 1.406850 m`；
- 世界姿态：长边沿 `+X`，宽度沿 `Y`，高度沿 `Z`；
- 最低点：`z=0`；
- 结构：3 级上行、2.5 m 中间平台、3 级下行。

## MuJoCo 中的姿态

当前实际场景使用：

```xml
<body name="steel_stair"
      pos="0 0.936 0"
      quat="0.70710678 0.70710678 0 0">
```

MuJoCo 四元数顺序为 `w x y z`。该姿态是结合正视、侧视和斜视渲染确认的；不要只依据 STL 原始包围盒判断上下方向。

## 已测尺寸

- 踏步深度约 `0.18 m`；
- 踏步净宽约 `0.71 m`；
- 平台尺寸约 `2.5 × 0.8 m`；
- 上行级高：`0.1950 / 0.1853 / 0.1852 / 0.2245 m`；
- 下行级高：`0.2245 / 0.1852 / 0.1853 / 0.1950 m`。

这些是从当前 STL 得到的估计值；若后续取得新版 CAD 或现场实测尺寸，应重新生成几何 JSON 并完成全部碰撞回归。
