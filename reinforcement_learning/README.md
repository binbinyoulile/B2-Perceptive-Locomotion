# 强化学习工作区

本目录用于后续自研 Gymnasium 环境、PPO 训练配置和评测脚本。当前只有目录骨架，不包含训练代码、训练检查点或外部参考工程快照。

## 目录

```text
reinforcement_learning/
├─ src/       环境、奖励、观测和训练入口
├─ configs/   场景、PPO、课程学习配置
├─ tests/     环境接口和数值边界测试
└─ README.md
```

## 第一版环境的最小要求

- 行为符合 Gymnasium API；
- 明确动作空间、观测空间、控制频率和终止条件；
- 固定随机种子，可复现实验；
- 奖励分项可开关，便于消融；
- 能记录速度、姿态、足端接触、力矩和能耗；
- 支持无渲染批量运行；
- 有固定动作、随机动作和站立策略自检。

## 开发顺序

1. 平地站立环境；
2. 平地速度跟踪；
3. 0.08 m 单级台阶；
4. 多级低台阶；
5. 完整钢梯上行、平台和下行；
6. 域随机化和鲁棒性评测。

在平地环境通过接口测试和多种子评测前，不直接开始完整楼梯训练。
