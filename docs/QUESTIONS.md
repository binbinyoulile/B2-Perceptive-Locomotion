## 【二、已采用合理默认值，后续如需变动再调整】

### 1. 足端与踏面摩擦

- **问题**：真机前是否需要重新标定橡胶足端与钢制踏面的接触参数？
- **目前临时采用的值**：滑动、扭转和滚动摩擦暂取 `0.8 / 0.02 / 0.01`；在真机实验前按实际足端和踏面状态标定。

### 2. 结构钢碰撞摩擦

- **问题**：立柱、侧梁和栏杆与足端或机身接触时采用什么摩擦参数？
- **目前临时采用的值**：暂按不锈钢/铁典型值取 `0.6 / 0.02 / 0.01`，尚未现场标定。

### 3. 单级课程台阶

- **问题**：进入完整楼梯前，课程学习使用的单级台阶尺寸是否调整？
- **目前临时采用的值**：高度 `0.08 m`、深度 `0.55 m`、宽度 `0.80 m`。该场景是独立课程测试，不等同于 STL 第一级的约 `0.195 m` 高、`0.18 m` 深踏面。

### 4. 控制步长与控制频率

- **问题**：强化学习阶段是否需要改变控制频率？
- **目前临时采用的值**：MuJoCo 步长暂取 `0.002 s`，每个仿真步计算一次 PD；强化学习环境建立后再确定控制分频和最终频率。

### 5. PD 增益与站立姿态

- **问题**：是否采用老师提供或真机推荐的 PD 参数？
- **目前临时采用的值**：12 个关节目标角为 `(hip, thigh, calf) = (0.0, 0.9, -1.8) rad`；保守增益为 `kp=60`、`kd=2.0`。平地站立测试已通过，后续训练若修改需重新做稳定性回归。

### 6. 载荷与足端模型

- **问题**：是否需要加入背部载荷、磨损足端或保护架？
- **目前临时采用的值**：使用官方 Go2 默认质量、质心和足端几何，不增加额外载荷，不模拟足端磨损或柔性。
