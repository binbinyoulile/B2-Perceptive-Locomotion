# B2 跨级姿态：前足踩 0.195 m、后足在地面的静态解与动力学验证

> 时间：2026-11-06
> 目标：解决"跨级姿态失稳"。要求机头净空 > 5 cm、前腿护板不磕台阶、
> kp=800 下关节不顶限位且机身不塌。
> 复现：`D:\Python313\python.exe .\experiments\b2\b2_step_pose.py --render`
> 预览：`D:\Python313\python.exe .\experiments\b2\b2_step_view.py`

---

## 1. 怎么搜的

四个自由度上做网格 + 局部加密：

| 变量 | 范围 | 步长 |
|---|---|---|
| 机身 pitch（抬头为正） | 0~25° | 2.5°（加密 0.5°） |
| 机身 x | −0.05~0.20 m | 25 mm（加密 10 mm） |
| 机身 z | 0.34~0.56 m | 20 mm（加密 5 mm） |
| 后足足心 x | −0.50~−0.15 m | 50 mm（加密 10 mm） |

前足固定在**第一级踏面中心** x=0.3066 m、z=0.195+0.032；后足在地面 z=0.032。
给定机身位姿与世界足位，用两连杆逆解求出 12 个关节角，再用 MuJoCo 的
`mj_geomDistance` 逐对量"机身/机头/雷达/四条小腿护板 vs 一级/二级/三级踏板"的真实距离
（不是靠包围盒估）。

**硬约束**（不满足直接淘汰）：

1. 机头净空 > 5 cm、机身净空 > 2 cm、前腿护板 > 5 mm；
2. 关节余量 > 0.08 rad（calf 限位 −2.82，thigh −0.94~4.69）；
3. **重心必须落在支撑多边形内**，前后各留 5 cm——这一条最容易被忽略：
   最初只优化"机头净空"，搜索把机身一直往后推，结果重心跑到后足后面，一放就翻；
4. 腿的倾斜方向要自然（后足在后髋之后 5~45 cm、前足在前髋之前 0~25 cm），
   否则会搜出"后足伸到身体前面"这种虽然几何可行、动力学上必滑的姿势。

可行候选 2196 个（其中 pitch=0 的 2196 个里挑最低的那个作为 A 方案）。

## 2. A（只蹲低）vs B（抬头翘尾）

| | A 只蹲低 | B 抬头翘尾 |
|---|---|---|
| 俯仰角 | 0.0° | **18.0°** |
| 机身 (x, y, z) | (+0.005, 0.468, 0.540) | (−0.070, 0.468, 0.580) |
| 后足 x | −0.520 | −0.520 |
| 机头净空（指令 / 落地后） | 9.5 / — cm | 24.4 / **23.7 cm** |
| 机身净空 | 17.0 cm | 29.5 / 27.9 cm |
| 前腿护板净空 | 4.2 cm | 4.3 / 3.9 cm |
| 关节最小余量 | 0.61 rad | **1.11 rad** |
| 前腿 thigh / calf | +1.191 / −2.211（伸展 45%） | +1.030 / −1.711（伸展 66%） |
| 后腿 thigh / calf | +1.048 / −1.358（伸展 78%） | +1.453 / −1.680（伸展 67%） |
| 4 s PD 落地机身 z | 0.5159 m（下沉 2.4 cm） | 0.5589 m（下沉 2.1 cm） |
| 高度抖动（峰峰） | 0.35 mm | 0.34 mm |
| 前足最大法向力 | 312 N（每足 156 N） | 279 N（每足 139 N） |
| 后足滑移（全程 / 最后 0.5 s） | 18.2 / 0.08 mm | 16.0 / 0.11 mm |

两个方案**都站得住**：高度抖动 0.3 mm、后足稳态滑移 0.1 mm（那 16~18 mm 是落地时
腿张开造成的横向位移，收敛后不再动）。

**选 B（18° 抬头）**，理由是余量：A 的 9.5 cm 只在"恰好站在踏面中心"时成立，
一旦往前挪 5 cm 或落地多一点，就逼近 5 cm 门槛；B 的 23.7 cm 能把机头安全地
送到二级踏板上方，这也正是"跨级"要走的下一步。

## 3. 最终姿态（已固化到 `configs/robot_config.B2_CROSS_STEP`）

```
pitch  = +18.0°（抬头）
机身   = (-0.070, 0.468, 0.580) m     # 指令位姿，落地后 z=0.5589
后足   = x -0.520 m（前足固定在 0.3066）
关节   = FL/FR: hip 0.0, thigh +1.0296, calf -1.7113
         RL/RR: hip 0.0, thigh +1.4531, calf -1.6801
kp/kd  = 800 / 20（50 Hz，+重力前馈）
```

落地后复测（机身 0.5589 m）：机头离二级踏板 **23.7 cm**、机身 27.9 cm、
前腿护板 3.9 cm；前足各承重约 139 N（合计 279 N，约 41% 体重，其余在后足）。

**前腿护板还会不会撞台阶？** 不会。前腿上没有任何碰撞体与踏板接触：
护板到一级踏面的最小距离 3.9 cm，而且这段距离出现在**足踝正上方**（护板本来就
悬在踏面之上），不是立面方向；小腿整段位于二级踏板面（0.3703 m）以上。

## 4. 三点说明

1. **PD 有 2.1 cm 下沉**。指令里写 z=0.580，落地后是 0.5589。所以配置里另记了
   `settled_base_z_m`；净空按落地后的状态复测（23.7 而不是 24.4 cm）。
2. **0.195 m 是这台狗的极限跨级**。前腿只能伸到 66%（thigh 1.03），因为足比髋高
   0.195 m 而髋到足的水平距离必须压在 0.25 m 以内（踏面只有 0.18 m 深）。
3. **模型里没有立面**。钢梯是 20 mm 薄板（模拟镂空格栅），所以"磕立面"在仿真里
   退化成"与踏板相交"。真实楼梯有立板时，护板余量要按 3.9 cm 再留一成。
