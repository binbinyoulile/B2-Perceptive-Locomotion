# B2 参数固化 + 平地站立 / 钢梯加载实测

> 时间：2026-11-06
> 结论：标准版 B2 在固化参数下可以稳定站在 **机身 0.4065 m（总高 0.6450 m）**，
> 抖动 0.00 mm；放进高摩擦钢梯场景后足端零滑移、无穿模、与钢梯零接触。
> 复现：`D:\Python313\python.exe .\experiments\b2\b2_stand_and_load.py`

## 2. 场景摩擦（"防滑格栅"）

### 2.1 先纠正一个机制

MuJoCo **不是**把两个 geom 的摩擦做乘积或平均，而是**逐元素取最大值**
（实测：地面 0.9、足端 0.4 → 接触 `friction = [0.9, 0.9, 0.02, 0.01, 0.01]`）。
所以把踏步调到 0.9 之后，接触的等效 μ 就是 **0.9**，足端的 0.4 被地面"覆盖"。
物理上这正好对应"橡胶足端踩在防滑格栅上"的上界值——想要真正的 0.4×0.9 组合，
得用 geom `priority`，本场景不需要。

### 2.2 改了什么

楼梯几何原来在两个 scene 里各存一份（14 KB×2）。这次抽成一份共用片段：

```
simulations/mujoco/steel_stair/stair_bodies.xml   # 地面 + 钢梯（碰撞体 + 视觉）
simulations/mujoco/go2_stairs_static/scene.xml           → <include> 它
simulations/mujoco/go2_stairs_static/scene_full_lidar.xml → <include> 它
simulations/mujoco/b2_stairs_static/scene.xml     （新）   → <include> 它
```

摩擦调整：**地面 + up/down 各级踏面 + 平台** 0.8 → **0.9**（8 个面）；
斜梁、栏杆、立柱这些不上人的构件保留 0.6。

回归验证（重构前 vs 重构后编译结果对比）：`nbody 16 / ngeom 107 / nq 19 / nkey 2 /
总质量 2433.9221 kg` 全部一致，几何位置尺寸逐项一致，**只有这 8 个面的摩擦数值变了**。

注意：`<include>` 的文件必须有**唯一根元素**，否则 MuJoCo 报 `Empty include file`；
片段因此用 `<fragment>…</fragment>` 包起来。

## 3. 测试结果

### 3.1 平地 PD 站立（6 s，最后 3 s 统计）

| 指标 | 值 |
|---|---|
| 机身高度 | **0.4065 m**（标准差 0.00 mm，峰峰 0.00 mm） |
| 总高 | **0.6450 m**（官网 645 mm） |
| 姿态 | \|pitch\| ≤ 0.30°，\|roll\| ≤ 0.10° |
| 水平漂移 | Δx 0.01 mm，Δy 0.00 mm（最后 1 s 残余 0.00 mm） |
| 接触 | 4 个（四足），最深穿透 2.86 mm |

高度偏差 0.0 mm——指令角是按"下沉后正好落在 0.4065 m"反解出来的，所以稳态无静差。

### 3.2 放进钢梯场景（先平地站稳，再平移，2 s 不做动作）

| 指标 | 值 |
|---|---|
| 机身高度 | 0.4070 m，足端 z 30.5~30.7 mm（踩在地面上） |
| 水平漂移 | Δx 0.05 mm，Δy 0.02 mm |
| **足端滑移** | FL 0.00 / FR 0.01 / RL 0.00 / RR 0.00 mm |
| **穿透** | 最深 1.92 mm（接触软度，不是几何错误） |
| 接触摩擦 | **μ = 0.9**（地面 0.9 覆盖足端 0.4） |
| 与钢梯接触 | 无（还没上梯，站位 x = −0.90 m） |

**结论：不打滑、不穿模、不抖。** 2 mm 级的穿透是 MuJoCo 默认接触刚度下 69 kg 静载的
正常压入量，不是模型错误；要压到 1 mm 以内需要调 `solref`，与本任务无关。

## 4. 为什么 kp 用 800 而不是 Isaac 的 160

用官方 `UNITREE_B2_CFG` 的 kp 160 / kd 5 做**被动站立**（没有上层控制器），B2 托不住：

| kp / kd | 结果（6 s，+重力前馈） |
|---|---|
| 160 / 5 | 髋关节缓慢外张到 0.39 rad，机身沉到 0.24 m 后继续塌 |
| 400 / 10 | 站住，机身 0.354 m，峰峰 0.65 mm |
| **800 / 20** | **站住，机身 0.4065 m，峰峰 0.00 mm** |
| 1200 / 30 | 50 Hz 控制下开始发散（两个接触点，翻倒） |
| 1600 / 40 | 发散（30 mm 级振荡） |

即：50 Hz 位置伺服下，69 kg 的深蹲站姿需要 kp ≈ 800，1600 以上会数值失稳。
这个值已写进 `B2_ROBOT.kp/kd` 与 `fsm.pd_kp/pd_kd`，并在注释里标了"本仓库标定"。

## 5. 已知限制

- **跨级姿态（前足上一级）这次没做结论。** 试过：前足踩第一级、后足在地面，
  前腿要折叠到接近 calf 限位（−2.82），kp 160 时下沉 6 cm 直到小腿护板接触踏面，
  kp 800 时该姿态在折叠限位附近直接失稳。结论是"水平机身的 0.195 m 跨级姿势需要
  抬头或更大的折叠余量"，属动力学问题，不在本次"站立/加载"范围内。
- 接触穿透 1.9~2.9 mm 是软接触压入量；如需更硬地面要调 `solref`，会牺牲稳定性。
- 场景里踏步仍是 20 mm 薄板（镂空模拟），没有建格栅网格；摩擦已按格栅取值。
- 摩擦 0.9 是经验上界，未做真机标定；若实测偏低，只需改
  `steel_stair/stair_bodies.xml` 一个文件，三个场景同时生效。
